Widget per iPhone

Le app web non possono avere widget propri su iPhone, quindi il widget passa dall'app gratuita Scriptable. Mostra oggi e i prossimi giorni sulla schermata Home e sulla schermata di blocco, con i colori e la foto di sfondo del calendario. Si aggiorna circa ogni 15 minuti.

  1. Installa Scriptable dall'App Store.
  2. Copia questo codice: 
    // Calendario: il widget del nostro calendario.
// Scarica ogni volta l'ultima versione dal sito; offline usa l'ultima copia.
const url = 'https://ramonpegoretti.github.io/SharedCalendar/widget/calendario.js'
const fm = FileManager.local()
const file = fm.joinPath(fm.documentsDirectory(), 'calendario-widget.js')
try {
  const req = new Request(url)
  const code = await req.loadString()
  if (req.response.statusCode === 200) fm.writeString(file, code)
} catch (e) {}
await new Function(fm.readString(file) + '\nreturn Calendario')().run()
  3. Apri Scriptable, tocca +, incolla il codice e chiama lo script Calendario.
  4. Tocca lo script per avviarlo e accedi con il tuo username e la tua password. La password non viene salvata.
  5. Sulla schermata Home tieni premuto, tocca Modifica › Aggiungi widget, scegli Scriptable e la misura che preferisci.
  6. Tieni premuto il nuovo widget, tocca Modifica widget e come Script scegli Calendario.
  7. Per la schermata di blocco: tienila premuta, tocca Personalizza, aggiungi un widget Scriptable e scegli di nuovo Calendario.

Toccando il widget si apre il calendario su quel giorno. Per uscire, apri lo script in Scriptable e scegli Esci.

iPhone widget

Web apps can't have widgets of their own on iPhone, so the widget runs in the free Scriptable app. It shows today and the next few days on the Home Screen and the Lock Screen, with the calendar's colors and background photo. It updates about every 15 minutes.

  1. Install Scriptable from the App Store.
  2. Copy this code: 
    // Calendario: il widget del nostro calendario.
// Scarica ogni volta l'ultima versione dal sito; offline usa l'ultima copia.
const url = 'https://ramonpegoretti.github.io/SharedCalendar/widget/calendario.js'
const fm = FileManager.local()
const file = fm.joinPath(fm.documentsDirectory(), 'calendario-widget.js')
try {
  const req = new Request(url)
  const code = await req.loadString()
  if (req.response.statusCode === 200) fm.writeString(file, code)
} catch (e) {}
await new Function(fm.readString(file) + '\nreturn Calendario')().run()
  3. Open Scriptable, tap +, paste the code and name the script Calendario.
  4. Tap the script to run it and log in with your username and password. The password is not saved.
  5. On the Home Screen, touch and hold, tap Edit › Add Widget, pick Scriptable and the size you like.
  6. Touch and hold the new widget, tap Edit Widget and pick Calendario as the Script.
  7. For the Lock Screen: touch and hold it, tap Customize, add a Scriptable widget and pick Calendario again.

Tapping the widget opens the calendar on that day. To log out, run the script in Scriptable and pick Log out.
